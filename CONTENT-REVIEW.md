## Wording to look at

1. **Hall: "Anyone can pray anywhere in the hall; there are no reserved places."** Masjid Putra has a separate women's area, and the imam's position is fixed. Visitors may see this and feel the text was wrong. One option: "There are no reserved seats for rank or wealth; men and women each have their own area."
2. **Rows: "Whoever arrives first stands at the front."** This holds within the men's rows. The same point about separate areas applies.
3. **FAQ: "Is Allah a different God? … Arabic-speaking Christians use it too."** This is accurate in general. But use of the word by non-Muslims has been a legal and political issue in Malaysia, so the mosque may want to word this answer itself.
4. **Ablution "Know more": "Many mosques today use push taps and timers to follow his example."** The motive is asserted. A softer version: "…push taps and timers, in the same spirit."
5. **Ablution steps.** The steps run Intention, Hands, Mouth, Nose, Face, Arms, Head and ears, Feet. Check that this matches the Shafi'i practice taught locally. For example, should ears be a separate step, and should the hands be washed three times?
6. **Mihrab: "From Malaysia, that's roughly west-northwest."** This is correct for Putrajaya (about 292°). Keep it if the station plaque is oriented to match.
7. **Adhan words.** The table gives the common form, which opens with four takbirs. If Masjid Putra's muezzin uses a variant, match it.
